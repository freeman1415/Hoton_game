# Хотон: Дело о пропавшей Капсуле

Видеоигра с маскотами фестиваля «Хотон» (Якутск). Детективная история на 5–10 минут: за два часа до открытия фестиваля «Детектив» пропала Капсула Хотона, и гость вместе с пятью маскотами ищет, где она, кто её спрятал и зачем. Пять мини-игр, детективный блокнот, финальная дедукция и три концовки.

## Скачать

**[Последний релиз — Windows и Linux](https://github.com/freeman1415/Hoton_game/releases/latest)**

- **Windows 10/11 (64 бит):** распакуйте `HotonGame-Windows-x64.zip` и запустите `HotonGame.exe`. Если появится SmartScreen — «Подробнее» → «Выполнить в любом случае».
- **Linux (x86_64):** распакуйте `HotonGame-Linux-x64.zip` и запустите `HotonGame.sh`.

Установка и интернет не нужны. Нужна видеокарта с OpenGL 3.3 (подойдёт встроенная).

Трейлер: [trailer/hoton_trailer_30s.mp4](trailer/hoton_trailer_30s.mp4)

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | ходить, выбирать |
| Enter | говорить, подтверждать |
| Tab | детективный блокнот |
| Esc | меню, пропустить заставку |
| Удержание R | начать заново |

Проект — в папке `game/`, открывать в **Godot 4.7** (`game/project.godot`). Сборка, структура и соглашения — [`docs/TECH.md`](docs/TECH.md), дизайн и сюжет — [`docs/GAME.md`](docs/GAME.md), ассеты и лицензии — [`docs/ASSETS.md`](docs/ASSETS.md).
