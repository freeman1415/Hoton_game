# docs/ASSETS.md — реестр ассетов и лицензий

Каждый файл, попадающий в игру или в репозиторий, — строка здесь. Без подтверждённой лицензии — ⚠️, в релизную сборку не идёт.

Статусы: ✅ можно использовать · 📎 только референс · ⚠️ лицензия не подтверждена

## Сгенерированный арт (PixelLab, Retro Diffusion)

Подключены MCP-генераторы пиксель-арта (2026-10-14). По ТЗ («не ИИ-слоп») сгенерированное — **только черновик**: в игру идёт после ручной перерисовки. Сырой вывод — в `pixellab-forge-output/` (в git не попадает). Каждый файл, дошедший до `game/`, вносится сюда с пометкой «ИИ-черновик → перерисовано», указанием сервиса и проверкой его условий на коммерческое и публичное использование.

## Пиксель-арт игры (`game/art/`) — черновик ✏️

Нарисован 2026-10-14 скриптом `tools/pixel_art/` (ИИ-ассистент, примитивы PIL, без нейрогенераторов) по референсам организаторов из `assets/` и картинкам маскотов с hotonfest.ru. Акцентный цвет `#F29F4F` и тёмный `#1E293B` взяты с сайта (`tokens.css`).

**Статус ✏️ — черновик, сделанный ИИ.** По ТЗ («не ИИ-слоп») до фестиваля команда должна **перерисовать его вручную** (Aseprite и т. п.), сохраняя размеры и точку ног (низ спрайта), — тогда код менять не придётся. Перерисованный файл убрать из `tools/pixel_art/build.py`, иначе сборка его затрёт. Сторонних ассетов и лицензий здесь нет.
