# docs/GOTCHAS.md — подводные камни

Добавляй с датой и причиной.

## Контент и ТЗ

- **Маскоты — наши.** Организаторские картинки в `assets/` — только референс. Не тащить их в релиз как финальные спрайты.
- **Сулуса нет среди монохромных референсов** в `assets/`, он только на общем арте `assets/all_mascots.jpg`. Отдельный цветной арт — на сайте: `https://hotonfest.ru/includes/images/сулус.png` (найден 2026-10-14).
- **`tools/pixel_art/build.py` перезаписывает `game/art/`.** Перерисовал спрайт вручную — убери его из сборки, иначе следующий запуск затрёт правки (2026-10-14).
- **Пиксель-арт в `game/art/` — ИИ-черновик** (нарисован ИИ-ассистент скриптом). До фестиваля перерисовать вручную, см. `docs/ASSETS.md` (2026-10-14).
- **Цветной референс есть.** Монохромные PNG — не единственный источник: в `all_mascots.jpg` видны цвета и костюмы всех пятерых.
- **6+ строго.** Детектив легко скатывается в убийства и кровь. Допустимо: пропажи, загадки, улики, кражи безобидных предметов. Недопустимо: трупы, оружие с насилием, алкоголь, сигареты. Нуарные атрибуты (сигарета, виски, пистолет) — исключить даже как антураж.
- **«Не ИИ-слоп».** Сырые нейроассеты не катят. Только как черновик с ручной доработкой.
- **Игра для фестиваля.** Сотни людей подряд, короткая сессия, понятное управление без обучения, быстрый рестарт, устойчивость к зажатым клавишам (автоповтор ОС! см. BUG-002). Посетитель может уйти посреди игры — нужен автосброс на титульный экран по бездействию.
- **Репозиторий на GitHub публичный.** Никаких чужих ассетов без лицензии в git: опенинг JoJo пришлось вырезать из всей истории (2026-10-14). Локальные «временные» файлы держать вне репозитория (например, `C:\Projects\Hoton_Game_local_assets\`).
- **Хаб сгенерирован скриптом (2026-10-14), дальше правим в редакторе.** `world.tscn` и `backstage.tscn` один раз собраны генератором; раскладку декораций теперь двигать в редакторе Godot, узлы — в `Decor`.
- **Ритм-игра: ноты и трек из одного скрипта.** Карту нот (`lenya_chart.gd`) руками не править — пересобирать `tools/music/lenya_song.py`, иначе ноты разъедутся с музыкой (2026-10-14).

## Godot

- **Регистр путей.** `res://`-пути должны совпадать с именем файла буква в букву. Windows-редактор прощает ошибку, экспорт и Linux — нет (BUG-001, 2026-10-14).
- **Переименовывать файлы — только в FileSystem-доке Godot**, не в проводнике: редактор обновит ссылки в сценах. `preload("res://...")` в скриптах он не правит — их проверять вручную через поиск.
- **Раскладка.** `event.keycode` зависит от раскладки, на фестивальных ПК будет русская. В Input Map — physical keycode (BUG-006).
- **Версия — строго 4.7.** Разные версии у членов команды → конфликты в `.tscn` (`unique_id`, `uid`).
- **`.godot/` не коммитить** — кэш, пересоздаётся. Уже в `game/.gitignore`.
- **`.tmp` рядом со сценами** (вида `main.tscn14231560033.tmp`) — мусор от сохранения при сбое редактора. Удалять, в git не класть (уже в `/.gitignore`).
- **`--import` пишет `Unrecognized UID: "uid://cxuyggswuob6m"`** — это главная сцена `world.tscn`, которую Godot пытается разрешить до сканирования файлов. Безвредно: обычный запуск проходит без ошибок (проверено 2026-10-14, Godot 4.7.2).
- **Смена сцены удаляет текущую сцену вместе с её скриптами.** `await` в узле сцены после `change_scene_to_file()` уже не продолжится. Всё, что должно пережить переход (печати, позиция игрока), хранить в autoload `GameState` (2026-10-14).
- **Диалог не должен получить тот же Enter, что его открыл.** Игрок после `action()` вызывает `set_input_as_handled()`, иначе окно сразу пропустило бы печать первой реплики (2026-10-14).
- **Обрыв разговора — только через `Dialogue.cancel()`.** Он пересоздаёт окно: недоговорённая функция диалога ждала сигнала старого окна и исчезает вместе с ним. Просто спрятать окно нельзя — старый диалог «проснётся» на следующем Enter (2026-10-14).
- **Вариативные шрифты без настройки — самые тонкие.** `montserrat.ttf` / `nunito.ttf` по умолчанию рисуются Thin/ExtraLight. Толщина задаётся в `fonts/body.tres` / `header.tres` (`FontVariation`, ось `wght` = тег 2003265652) (2026-10-14).
- **Первый импорт после добавления шрифтов ругается** «No loader found for resource: res://fonts/*.ttf» — `.tres` грузятся раньше импорта `.ttf`. Второй запуск `--import` проходит чисто (2026-10-14).
- **`tools/pixel_art/build.py` маскотов больше не рисует** — это спрайты дизайнера, скопированные из `assets/new_assets/` (2026-10-14).
- **Новые скрипты без `.uid`.** Файлы `.gd`, созданные вне редактора, получают `.gd.uid` только после открытия проекта в редакторе. Открыть редактор и закоммитить появившиеся `.uid` (2026-10-14).
- **Окно диалога не останавливает ходьбу само:** он глотает события ввода, а игрок опрашивает `Input.get_vector()` напрямую. Для этого есть флаг `GameState.in_dialogue` (2026-10-14).
- **`uid` спасает от неверного `path`, но не всегда.** В `ritm/note.tscn` был `path="res://note.gd"` (файла нет), работало только за счёт `uid`. При потере `.uid` или в экспорте такое ломается — пути держать верными (BUG-007).
- **Логотип «Хотон» чёрный на прозрачном фоне** — на чёрном экране его не видно. В `title.gd` шейдер красит его в белый по альфе. Исходник 1363 px заранее уменьшен до 400 px: при nearest-фильтре и сжатии в 7 раз он рябит (2026-10-14).
- **Тесты пишут в настоящий `user://`.** Запуск проекта (и headless-тесты) трогает реальный `leaderboard.cfg` на этой машине. Перед показом на фестивальном ПК — сбросить рекорды `Ctrl+Shift+F12` на титульном экране.
- **Ошибка разбора в любом autoload'е ломает всю игру.** `GameState` не загрузится — не работает ничего, игра висит. Тип через `:=` GDScript выводит не всегда (`var x := a != null and b` — ошибка); при сомнении писать тип явно: `var x: bool = ...` (2026-10-14, пойман дымовым тестом сборки).
- **Релизная сборка не принимает путь к сцене в командной строке** («compiled without support for path overrides»). Для проверки сцен в сборке — `-- --smoke-test` (`docs/TECH.md` → «Экспорт»).
- **Linux-сборка собирается, но не проверена на живом Linux** — нет машины. Проверить, если на фестивале будет Linux.
- **Рендер — Compatibility (OpenGL 3.3)**, а не Forward+: тот мог не стартовать на слабом ПК (переключено 2026-10-14). Шейдеры писать с оглядкой на GL — не всё из Forward+ доступно.

- **Esc общий: его ловит меню паузы (autoload `PauseMenu`).** Сцена, которой Esc нужен самой (выход после поражения в мини-игре, пропуск заставки), вызывает `get_viewport().set_input_as_handled()` — текущая сцена получает ввод раньше autoload'ов, и меню тогда молчит. Иначе сцена сменится, а меню откроется и поставит на паузу уже новую сцену (2026-10-15).
- **После `change_scene_to_file()` у старой сцены нет `get_viewport()`** (null): в 4.7 сцена убирается из дерева сразу. `set_input_as_handled()` звать **до** перехода, иначе SCRIPT ERROR — в редакторе отладчик останавливает игру (заставка «не запускала» игру, 2026-10-15).
- **Пауза дерева глушит звук сцены, но не autoload'ов.** `AudioStreamPlayer` в сцене при `get_tree().paused` встаёт (песня ритм-игры ждёт), а `Music` и `Sfx` работают всегда (`PROCESS_MODE_ALWAYS`) — в меню и блокноте музыка играет, щелчки меню слышны (2026-10-15).

## Окружение (Windows)

- **Windows-консоль** может показывать кириллицу кракозябрами. `.docx` — это zip с `word/document.xml`, читать с явной UTF-8.
- **`pdftoppm` не установлен** — ИИ-ассистент не может читать PDF. ТЗ хранится в `.docx` (`docs/brief_case8.docx`).

## Музыка

- Лицензия должна допускать публичный показ. Источник и лицензия — в `docs/ASSETS.md`.
- **Вся музыка и звуки — свой синтез** (`tools/music/`), чужих семплов нет. WAV пересобираются скриптом: правки в Audacity и т. п. затрутся при следующем запуске (2026-10-15).
- **Петля трека — чанк `smpl` в WAV**, Godot читает его при импорте («Detect From WAV»). На всякий случай `Music` сам включает петлю, если импорт её не увидел (2026-10-15).

## Генераторы пиксель-арта (MCP)

- **PixelLab `generate_image`: референсы через MCP не проходят** (2026-10-15). Схема инструмента шлёт `{base64}`, а API ждёт `{image, size}` — ответ 422, и для `reference_images`, и для `style_image`. Без референса стиль не совпадает со спрайтами дизайнера, поэтому портреты и оформление сделаны из спрайтов дизайнера и скриптами `tools/pixel_art/`.
- **Кредиты на исходе:** PixelLab — 40 пробных генераций, Retro Diffusion — $0.50 (на 2026-10-15). На полный набор спрайтов не хватит.
