# docs/GOTCHAS.md — подводные камни

Добавляй с датой и причиной.

## Контент и ТЗ

- **Маскоты — наши.** Организаторские картинки в `assets/` — только референс. Не тащить их в релиз как финальные спрайты.
- **Сулус есть только на общем арте** `assets/all_mascots.jpg` (JPEG, цветной). Отдельного референса нет — рисуем по нему.
- **Цветной референс есть.** Монохромные PNG — не единственный источник: в `all_mascots.jpg` видны цвета и костюмы всех пятерых.
- **6+ строго.** Детектив легко скатывается в убийства и кровь. Допустимо: пропажи, загадки, улики, кражи безобидных предметов. Недопустимо: трупы, оружие с насилием, алкоголь, сигареты. Нуарные атрибуты (сигарета, виски, пистолет) — исключить даже как антураж.
- **«Не ИИ-слоп».** Сырые нейроассеты не катят. Только как черновик с ручной доработкой.
- **Игра для фестиваля.** Сотни людей подряд, короткая сессия, понятное управление без обучения, быстрый рестарт, устойчивость к зажатым клавишам (автоповтор ОС! см. BUG-002). Посетитель может уйти посреди игры — нужен автосброс на титульный экран по бездействию.
- **Музыка из JoJo** (`game/ritm/JojoS2_OP.ogg`) — чужой трек под авторским правом, оставлен временно по решению команды (2026-10-14). Перед фестивалем — заменить или получить права. См. `docs/ASSETS.md`.

## Godot

- **Регистр путей.** `res://`-пути должны совпадать с именем файла буква в букву. Windows-редактор прощает ошибку, экспорт и Linux — нет (BUG-001, 2026-10-14).
- **Переименовывать файлы — только в FileSystem-доке Godot**, не в проводнике: редактор обновит ссылки в сценах. `preload("res://...")` в скриптах он не правит — их проверять вручную через поиск.
- **Раскладка.** `event.keycode` зависит от раскладки, на фестивальных ПК будет русская. В Input Map — physical keycode (BUG-006).
- **Версия — строго 4.7.** Разные версии у членов команды → конфликты в `.tscn` (`unique_id`, `uid`).
- **`.godot/` не коммитить** — кэш, пересоздаётся. Уже в `game/.gitignore`.
- **`.tmp` рядом со сценами** (вида `main.tscn14231560033.tmp`) — мусор от сохранения при сбое редактора. Удалять, в git не класть (уже в `/.gitignore`).
- **`--import` пишет `Unrecognized UID: "uid://cxuyggswuob6m"`** — это главная сцена `world.tscn`, которую Godot пытается разрешить до сканирования файлов. Безвредно: обычный запуск проходит без ошибок (проверено 2026-10-14, Godot 4.7.2).
- **Смена сцены удаляет текущую сцену вместе с её скриптами.** `await` в узле сцены после `change_scene_to_file()` уже не продолжится. Всё, что должно пережить переход (печати, позиция игрока), хранить в autoload `GameState` (2026-10-14).
- **Новые скрипты без `.uid`.** Файлы `.gd`, созданные вне редактора, получают `.gd.uid` только после открытия проекта в редакторе. Открыть редактор и закоммитить появившиеся `.uid` (2026-10-14).
- **Пузырь Dialogue Manager листается по `ui_accept`, а не по нашему `enter`.** Поэтому `ui_accept` переопределён в Input Map (Enter, Space, E, Numpad Enter). Добавляешь клавишу в `enter` — добавь и в `ui_accept` (2026-10-14).
- **Пузырь диалога не останавливает ходьбу:** он глотает события ввода, а игрок опрашивает `Input.get_vector()` напрямую. Для этого есть флаг `GameState.in_dialogue` (2026-10-14).
- **Мини-игру из диалога запускать через `request_minigame()`**, а не сменой сцены прямо в мутации: пузырь живёт в текущей сцене и ещё ждёт следующую строку (2026-10-14).
- **Рендер Forward+ / D3D12** может не стартовать на слабом ПК. Проверить экспорт на целевом железе или перейти на Compatibility (`docs/TECH.md`).

## Окружение (Windows)

- **Windows-консоль** может показывать кириллицу кракозябрами. `.docx` — это zip с `word/document.xml`, читать с явной UTF-8.
- **`pdftoppm` не установлен** — ИИ-ассистент не может читать PDF. ТЗ хранится в `.docx` (`docs/brief_case8.docx`).
