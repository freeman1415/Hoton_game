# docs/SPRITES_SPEC.md — спецификация спрайтов

Список всех спрайтов игры: размер, привязка, что нарисовано. Нужен, чтобы перерисовать черновые спрайты (сейчас их нарисовал ИИ-ассистент скриптом `tools/pixel_art/`) — руками или с помощью генератора.

> **Правило проекта (ТЗ «не ИИ-слоп», `docs/ASSETS.md`):** сгенерированное нейросетью — только черновик. В игру идёт после ручной доработки дизайнером: чистка пикселей, палитра, обводка. В `docs/ASSETS.md` такой файл помечается «ИИ-черновик → перерисовано».

**Не перерисовывать:** маскоты Маня, Леня, Катя, Мойто, Сулус — это готовые спрайты дизайнера (`assets/new_assets/pixel_*.png`). Они — эталон стиля для всего остального.

---

## Общие правила (для всех спрайтов)

- **Стиль:** пиксель-арт в духе JRPG / Undertale + милые мультяшные маскоты фестиваля «Хотон» (Якутск). Как у спрайтов дизайнера: **чёрная обводка 1 px**, простые мягкие формы, плоская заливка, 1–2 тона тени, без градиентов и сглаживания.
- **Палитра брендбука** — «уютная, тёплая, яркая, но не кислотная»:
  - оранжевый `#E48824`, лососевый `#D48464`, коричневый `#604030`, голубой `#78B0C8`, красный `#CC5C60`, зелёный `#74B068`;
  - плюс белый `#FFFFFF`, кремовый `#FFF4E6`, тёмно-коричневый `#2A1B14`, чёрный контур `#000000`.
  - Не больше ~12–16 цветов на спрайт.
- **Формат:** PNG, **прозрачный фон**, точный размер в пикселях из таблицы, 1 пиксель = 1 пиксель (без масштабирования, без полупрозрачных краёв).
- **Вид:** 3/4 сверху (как в Undertale), персонажи — анфас, если не сказано иначе.
- **Привязка (важно для кода):** нижний край картинки = точка, где предмет или персонаж стоит на земле. Персонажи стоят ногами на самом нижнем ряду пикселей, по центру по горизонтали.
- **6+:** без оружия, крови, алкоголя, сигарет; детективные атрибуты — лупа, блокнот, шапка; без нуара.
- **Надписи:** генераторы портят кириллицу. Места под надписи оставлять пустыми плашками — текст «ХОТОН», «ЧАЙ», «ЦИРК», «КОСМОС», «ПРИЗЫ» дорисуем сами (пиксельный шрифт есть в `tools/pixel_art/festival.py`).
- **Темы прошлых фестивалей**, на которые много отсылок: «Ретро» (80-е, пластинки, кассеты), «Цирк» (шатёр, клоуны, горошек), «Космос» (костюмы и ракеты **из картона**, как на общем арте маскотов `assets/all_mascots.jpg`).

### Готовый промпт-шапка (вставлять перед описанием каждого спрайта)

```
Pixel art sprite, JRPG / Undertale style, cute cartoon festival mascot game.
1px pure black outline, simple soft shapes, flat colors, 1-2 shade tones, no gradients, no anti-aliasing, no dithering.
Warm cozy palette: orange #E48824, salmon #D48464, brown #604030, light blue #78B0C8, red #CC5C60, green #74B068, white, cream #FFF4E6.
Transparent background, exact size {W}x{H} pixels, object stands on the bottom edge, centered.
3/4 top-down view. Kid-friendly (6+). No text.
```

### «Собери эскиз» (Маня) — `game/art/minigames/manya_sketch.png`, 240×240

Это **рисунок Мани — схема фестиваля** на листе в клетку (тетрадь), детский «фломастерный» стиль. В игре режется на сетку **3×3 кусочка по 80×80**, поэтому у каждого кусочка должна быть своя заметная деталь. Раскладка повторяет хаб:

| | левый столбец | центр | правый столбец |
|---|---|---|---|
| **верх** | лекторий (доска + кафедра) | музыкальная сцена | **картонная ракета, обведённая красным кругом** + планета |
| **середина** | палатка арт-маркета | главная сцена | вешалка с костюмами и зеркало |
| **низ** | арка-вход | цирковой шатёр | шарики и чайная |

- Дорожки (светло-бежевые) соединяют кусочки: горизонтальная через середину, вертикальная от музыкальной сцены вниз к шатру.
- Красный круг вокруг ракеты обязателен — это улика.
- Правый верхний угол (x 200–240, y 4–18) оставить пустым: туда код пишет «для С.».

## Как сдать готовые спрайты

1. Положить PNG с **тем же именем и размером** в ту же папку `game/art/...` — код подхватит сам.
2. Убрать этот спрайт из `tools/pixel_art/build.py`, иначе следующий запуск сборки затрёт его черновиком.
3. Записать в `docs/ASSETS.md`: кто нарисовал, чем (если генератор — «ИИ-черновик → перерисовано»).
4. Открыть проект в Godot (импорт) и проверить сцену: ноги/основание на земле, ничего не обрезано.
